# 3-minute strategy logic

## Signal source

The bot uses the same `ta_engine.py` as BTC Signal Research Terminal v3.0. The core 3m signal is generated by `signal_history()` and therefore inherits the Terminal 3.0 families: trend, momentum, structure and flow/volume, dynamic regime thresholds, quality, coverage, RSI safeguards, breakout/pullback/reversal triggers and ATR/structure risk planning.

## Entry sequence

1. Wait for a **new completed BloFin 3m candle**.
2. Pull fresh BloFin 3m, 15m, 1h, 4h and 1d OHLCV.
3. Require the latest Terminal 3.0 3m marker to belong to that just-closed candle.
4. Calculate higher-timeframe context with weights:
   - 15m: 34%
   - 1h: 34%
   - 4h: 22%
   - 1d: 10%
5. Default minimum signed higher-timeframe context: `+6` for BUY / `-6` for SELL.
6. Default context agreement: at least 55%.
7. Block BUY when 1h <= -45, 4h <= -55, or 1d <= -65. SELL uses the mirrored rule.
8. Block ordinary range/squeeze entries unless the 3m trigger is a breakout/breakdown.
9. Block chasing when 3m extension is more than 3 ATR beyond EMA20 in the trade direction.
10. Reject stale signals if market price has moved more than 0.35 ATR from the signal close.
11. Reject entry if live bid/ask spread is above 8 bps.
12. Reject entry when a BTC position already exists or a risk guard is active.

## Execution

A market order is sent with attached mark-price stop-loss and take-profit. Terminal 3.0 provides the initial stop concept; the actual order shifts the plan by any small entry slippage so the approximate R geometry is preserved.

Default TP is 2R. The bot does not average down, martingale, pyramid, or automatically increase risk after a loss.

## Risk sizing

For linear contracts:

`risk_per_contract = |entry - stop| × contractValue`

`contracts = risk_usd / risk_per_contract`

The bot then rounds down to `lotSize` and applies exchange and software caps.

## Why higher timeframes are filters, not separate entries

The 3m candle controls timing. Higher timeframes are used to reject weak or strongly counter-trend 3m setups. This avoids entering multiple positions just because several correlated timeframes all say the same thing.
